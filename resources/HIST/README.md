# 河南科技学院 · 拾光课程表适配

适配 河南科技学院（青果 / KINGOSOFT 教务系统）的课表导入与空闲教室查询。

- 教务入口：http://jwgl.hist.edu.cn/cas/login.action
- 系统：青果(KINGOSOFT) 高校智慧校园教学综合服务平台（学校代码 10467）
- 已用真实导出文件校准：河南科技学院学生个人课表.xls（HTML/GBK）、河南科技学院空闲教室一览表(1).xls（HTML/GBK）

## 文件说明

| 文件 | 用途 |
| --- | --- |
| adapters.yaml | 适配器登记（HIST_01 课表、HIST_02 空闲教室） |
| hist_01.js | 课表导入：请求课表接口 - 解析 HTML 表格 - 保存课程 |
| hist_02.js | 空闲教室查询：解析"空闲教室一览表"报表 - 按星期/类型列出空闲教室 |

## HIST_01 课表导入

接口：/wsxk/xkjg.ckdgxsxdkchj_data10319.jsp?params=<base64>
- params = btoa('xn=2025&xq=0')；xn=学年，xq=0 秋季/1 春季；学号可省略。
- 返回 HTML 课表，真实列布局（导出/接口一致，已按内容自适应）：
  - 课程名列：形如 [2500T0002]大学生心理健康教育
  - 任课教师列：形如 [201201059]贾普君 [202201013]李金璐
  - 上课时间地点列：形如 6-8,10周 二[7-8] 弘毅楼A207(98) / 8-14周(双) 四[7-8] 弘毅楼A204(64)
- 解析器按内容识别"课程名/教师/时间地点"，兼容多种列布局。
- 作息支持夏/冬季切换；教室容量 (98) 已剥离。

真实课表自测：10 门课解析为 18 个课块，教师/地点/星期/节次/单双周全部正确。

## HIST_02 空闲教室查询

真实报表结构（导出为 HTML）：
- 标题：河南科技学院...空闲教室一览表 第1-18周 星期一（一个导出对应一个"星期"）
- 其下按 校区/教室类型 分组；每组一张 教室|容量 小表列出空闲教室。

使用：登录教务系统打开"空闲教室一览表"（选好星期）+ 点"开始查询"。
脚本自动识别星期、按类型列出空闲教室（支持 iframe 与当前页扫描）。

真实报表结构自测：正确识别星期"一"，并按类型（实验室/计算机房等）列出空闲教室。

## 如何让软件加载这些适配

warehouse 有分支保护：走 PR 到 pending 分支 由维护者合并、CI 重编译索引；
或在自己的 fork 上用开发者模式（更多 > 点击应用图标 5 次 > 更新仓库 > 自定义仓库 填入 fork）。
修改 index/root_index.yaml 后需用 scripts/build_data.py 重新生成 school_index.pb。

本地校验：node hist-shiguang/verify_adapter.cjs [课表.html]（可传入真实导出 HTML 复测）。
