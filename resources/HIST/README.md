# 河南科技学院 · 拾光课程表适配

适配 河南科技学院（青果 / KINGOSOFT 教务系统）的课表导入与空闲教室查询。

- 教务入口：http://jwgl.hist.edu.cn/cas/login.action
- 系统：青果(KINGOSOFT) 高校智慧校园教学综合服务平台（学校代码 10467）

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `adapters.yaml` | 适配器登记（HIST_01 课表、HIST_02 空闲教室） |
| `hist_01.js` | **课表导入**：请求课表接口 → 解析 HTML 表格 → 保存课程 |
| `hist_02.js` | **空闲教室查询**：登录后在“空闲教室”报表中按星期/节次列出空闲教室 |

## HIST_01 课表导入

原理（依据公开接口与分析）：
- 接口：`/wsxk/xkjg.ckdgxsxdkchj_data10319.jsp?params=<base64>`
- `params` = `btoa('xn=2025&xq=0')`
  - `xn`＝学年（如 2025 表示 2025-2026 学年）
  - `xq`＝学期（0＝第一学期/秋，1＝第二学期/春）
  - 学号/uid(`xh`) 可省略，使用会话即可。
- 返回为 HTML 课表表格，脚本用 `DOMParser` 解析并合并周次。

### 使用步骤
1. 在拾光课程表「导入 → 教务」中选择 **河南科技学院适配教务**（或自定义仓库拉取后出现）。
2. 进入教务系统 WebView 登录（CAS），成功后无需再点登录。
3. 点击“执行导入” → 选择学年/学期 → 选择作息（夏/冬）。
4. 导入完成。

### 注意
- 菜单编号 `10319` 可能随系统版本变化，若导入失败请看开发者日志里的原始 HTML。
- GBK 编码：脚本会先按 UTF-8 解码，若出现乱码再按 GBK 重试。

## HIST_02 空闲教室查询

- 该功能依赖学校教务“空闲教室 / 教室使用情况”报表，需登录后访问。
- 支持两种方式：
  1. 粘贴“空闲教室”报表 **URL**（登录后从浏览器地址栏复制）；
  2. 在教务页面打开该报表后直接扫描当前页面。
- 选择星期后列出该天各节次的空闲教室。

> 由于“空闲教室”报表的菜单路径与表格结构随学校配置不同，**请在真机/开发者模式实测**，
> 若列项与预期不符，请更新 `DEFAULT_FREE_URL` 或调整 `findFreeClassroomTable` 的识别规则。
